Laser (Lumino Pro) — Therapy Platform

Dedicated Full-Screen Kiosk Laser Therapy Management Platform on Raspberry Pi

☼ In Active Development Domain: Medical Laser Technology OS: Raspberry Pi OS (Linux) UI: PyQt6 Kiosk Shell

Project Overview

Medical laser therapy devices require strict authorization to prevent accidental laser radiation emission, consistent treatment repeatability across acute and chronic patient conditions, and an appliance-grade user interface that launches directly without exposing operating system clutter.

Lumino Pro was built as a dedicated kiosk platform running on Raspberry Pi OS. It delivers a clinical touchscreen interface with PIN-code security barriers, structured therapy presets, pulse frequency modulation controllers, GPIO emergency shutoff monitoring, and session auditing in SQLite.

The Engineering Problem

Clinical laser therapy introduces unique safety and workflow challenges:

  • Unauthorized users must be physically and digitally prevented from firing laser emitters without clinician authentication.
  • Therapists need preset wavelength and pulse repetition protocols for varied clinical conditions (pain management, wound healing, deep tissue rehabilitation).
  • The hardware emergency interlock must instantly cut laser firing relays if safety enclosures are compromised.
  • The application must automatically start upon unit power-on and recover gracefully if unexpected exceptions occur.

The Solution Built

Developed a full-screen PyQt6 touch kiosk application deployed via Linux systemd. Built a custom virtual PIN keypad modal for access validation, an extensible therapy protocol management engine, automated laser duration countdowns, and treatment auditing.

System Architecture

Appliance Kiosk Shell (PyQt6 / Raspberry Pi OS systemd user daemon)
    ↓
Clinician PIN Authentication Layer (Security Barrier • Virtual Keypad)
    ↓
Therapy Protocol Engine (Acute / Chronic Presets • Pulse Frequency Modulation)
    ↓
Hardware Safety Interlock (GPIO Monitoring • Emergency Stop State)
    ↓
Session Audit Trail (SQLite Persistence • Energy Delivered & Timestamps)

Key Capabilities

  • Appliance Kiosk Experience: Full-screen PyQt6 shell with no visible desktop shortcuts, taskbars, or window chrome.
  • Role-Protected PIN Gate: Custom virtual on-screen keypad requiring valid practitioner credentials to unlock laser controls.
  • Comprehensive Protocol Presets: Pre-programmed dosage and timing templates for acute pain, chronic inflammation, and rehabilitation.
  • Timer & Pulse Frequency Control: High-precision treatment countdown with audio-visual notifications upon completion.
  • Hardware Interlock Supervisor: Monitors physical safety cutoffs through Raspberry Pi GPIO lines.
  • Session History Auditing: Records treatment duration, energy dosage, and timestamp to a local SQLite database.

Key Technical Challenges

1. Preventing Underlying Linux Shell Access
Operators could theoretically trigger escape shortcuts to access the underlying desktop. Hardened the X11 session configuration, disabled virtual terminal switching (Ctrl+Alt+F1), and configured systemd with Restart=always.
2. Strict Clinical Validation Boundaries
Built dual-layer input validation ensuring laser power outputs and timer durations cannot exceed pre-configured regulatory and clinical safety envelopes.
Disclaimer: Built as a software and embedded interface platform. Does not claim medical device clinical certification or regulatory approval.
